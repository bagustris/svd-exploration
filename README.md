# svd-exploration
Exploring voice disorder with SVD neutral vowels with Nkululeko

These files are located in a directory under nkululeko root directory (e.g., `exp_svd`)

The best performance is a combination (ensemble via average) of `exp_os.ini`, `exp_praat_a_n.ini`, and `exp_hubert.ini`. 
All used SMOTE oversampling for class balancing.
